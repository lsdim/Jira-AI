# Jira AI Helper (Gemini) - Project Overview

Цей проект є розширенням для браузера (Chrome/Firefox), призначеним для автоматизації процесу закриття заявок у Jira. Воно використовує Google Gemini API для генерації описів виконаних робіт та коментарів для користувачів на основі контексту заявки та технічних нотаток спеціаліста.

## Основні технології
- **JavaScript (Vanilla)**: Основна логіка розширення та взаємодія з DOM Jira.
- **Manifest V3**: Сучасний стандарт розширень браузера.
- **Google Gemini API**: Штучний інтелект для обробки природної мови та генерації відповідей.
- **Chrome Storage API**: Для надійного збереження API-ключів та користувацьких промптів.

## Архітектура
- `manifest.json`: Визначає дозволи, домени (`jira.ukrposhta.loc`) та підключені скрипти.
- `content.js`: Впроваджує кнопку "AI Відповідь" у діалогові вікна Jira, зчитує дані (Summary/Description) та заповнює поля (`customfield_10831`, `comment`, `customfield_10632`). Підтримує роботу з TinyMCE iframe.
- `defaults.js`: Містить промпт за замовчуванням та змінні для підстановки (`{{summary}}`, `{{description}}`, `{{manualNotes}}`).
- `options.html/js`: Сторінка налаштувань для введення API-ключа та редагування системного промпту.
- `content.css`: Стилізація модального вікна уточнення та кнопки в інтерфейсі Jira.

## Розробка та тестування
1. При розробці, робити лише точні "хірургічні" зміни там де це потрібно, не переписувати весь код, щоб не зламати те, що вже працює.
2. Не видаляти коментарі, можна лише доповнювати чи модифікувати.
### Як запустити:
1. Завантажте папку `extension` у браузер через режим розробника.
2. Налаштуйте Gemini API Key у вікні параметрів розширення.
3. Відкрийте Jira, перейдіть до заявки та натисніть "Опрацьована".

### Конвенції розробки:
- **Селектори Jira**: Всі ID та класи для взаємодії з Jira винесені в об'єкт `JIRA_CONFIG` у `content.js`.
- **Механізм Fallback**: При виникненні помилок (ліміти запитів, недоступність моделі), розширення автоматично ітерує по списку доступних моделей Gemini.
- **Взаємодія з редактором**: Для поля коментаря використовується прямий запис у `body#tinymce` всередині iframe, що гарантує коректне відображення у візуальному редакторі Jira.
