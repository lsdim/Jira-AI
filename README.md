# Jira AI Helper (Gemini)

Браузерне розширення для автоматизації закриття заявок у Jira за допомогою штучного інтелекту Google Gemini.

## Основні можливості
- Додає кнопку **"AI Відповідь"** безпосередньо у вікно переходу Jira (наприклад, при зміні статусу на "Опрацьована").
- Автоматично зчитує тему та опис заявки.
- Дозволяє ввести короткі технічні нотатки для уточнення результату.
- Генерує звіт у поле "Виконані роботи" (формат Проблема/Вирішення).
- Формує ввічливу відповідь для користувача в полі "Коментар".
- Автоматично обирає результат обробки ("Вирішена").

## Встановлення

### Chrome / Edge / Brave
1. Відкрийте сторінку `chrome://extensions/`.
2. Увімкніть **Developer mode** (режим розробника) у правому верхньому куті.
3. Натисніть кнопку **Load unpacked** (завантажити розпаковане розширення).
4. Виберіть папку `extension` з цього репозиторію.

### Firefox
1. Відкрийте `about:debugging#/runtime/this-firefox`.
2. Натисніть **Load Temporary Add-on** (завантажити тимчасове розширення).
3. Виберіть файл `manifest.json` у папці `extension`.

## Налаштування
1. Отримайте API ключ Gemini на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Натисніть на іконку розширення в панелі браузера.
3. Вставте ваш ключ у поле та натисніть **Зберегти**.

## Як користуватися
1. Відкрийте будь-яку заявку в Jira.
2. Натисніть кнопку статусу (наприклад, **Опрацьована**), щоб відкрилося модальне вікно Jira.
3. У футері вікна натисніть нову кнопку **AI Відповідь**.
4. Введіть коротко, що було зроблено (за бажанням), та натисніть **Згенерувати**.
5. Перевірте заповнені поля та завершіть опрацювання заявки стандартною кнопкою Jira.
